Негоциар — не «ещё один промпт про переговоры». Это советник, который работает против
канона из **275 принципов** управленческой борьбы и социальной технологии (традиция
Владимира Тарасова, записи 157 живых занятий Арти Галиева) и библиотеки из **1019 реальных
разборов** — живых ролевых игр с разбором ведущего. Вы описываете ситуацию как есть — с
перепиской, датами, суммами, тем, что уже сказано вслух. Он восстанавливает, что происходит на
самом деле, включая то, чего не видно изнутри, называет закон, который этим управляет, и
даёт лестницу ходов: вопрос за вопросом, с возражениями другой стороны и ответами на них,
худшим сценарием и развилками. Стратег, а не копирайтер: текст сообщения пишет только по
прямой просьбе.

Этот репозиторий — перевод всего этого на русский: правил навыка, канона и библиотеки
случаев, чтобы читать канон по-русски и искать по базе русскими словами.

## Состояние перевода

Перевод делается пакетами, с проверкой структуры, хешей и остатков испанского; статусы
честные. Актуальные цифры — `translation/canon-status.json` и
`translation/cases-status.json`; в каждом случае есть поле `translation_status`
(`machine_draft` / `title_only` / `untranslated`). Общий статус корпуса не выше
`machine_draft`, пока независимый проход не поднимет его до `reviewed`. Сомнительные
места — `translation/translation-review.jsonl`. Словарь терминов —
`translation/glossary.md` (статус `draft` до утверждения).

| Часть | Объём | Статус |
|---|---|---|
| Правила навыка `SKILL.md` | 1 файл | см. `translation/canon-status.json` |
| Канон: 10 доменов + архитектура + служебные файлы | 275 принципов | см. `translation/canon-status.json` |
| Библиотека случаев | 1019 случаев | см. `translation/cases-status.json` |
| Пример-разбор `EJEMPLO-NOVATO.md` | 1 файл | в исходнике уже по-русски, перенесён как есть |

## Установка

Работает в **Claude Code** (и как плагин Claude). Нужен `node` в `PATH` — он ищет по базе
случаев.

```
/plugin marketplace add DmitriyVOstapenko/negociar-ru
/plugin install negociar-ru@negociar-ru-marketplace
```

Перезапустите Claude Code. Навык называется `negociar-ru`, чтобы не конфликтовать с
оригинальным `negociar`, если он тоже установлен.

## Как получить настоящий ответ

Это навык, который не награждает краткость. Вставляйте сырое — переписку, письмо, скриншот,
точные слова другой стороны; говорите, что уже сказано вслух; давайте даты, суммы, сроки,
длину пауз; объясняйте, кто кому кто и кто может встать и уйти; говорите, чего хотите и чего
боитесь; отвечайте на его уточняющие вопросы; возражайте, если он ошибся, — с недостающим
фактом; называйте ограничения («не признавать вину письменно», «только звонок»).

## Что происходит на вашей машине

Один скрипт поиска `skills/negociar-ru/scripts/buscar.mjs` — читает только свои файлы, не
пишет, не ходит в сеть. Инструменты перевода в `tools/` — локальные, без сети. Телеметрии нет.
