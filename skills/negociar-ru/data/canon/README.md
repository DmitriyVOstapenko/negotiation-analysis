## Навык и библиотека случаев

Этот канон питает **навык `/negociar`** (`.claude/skills/negociar/`), который отвечает из
канона + **библиотеки случаев** (`casos.json`, 1019 реальных отобранных случаев: рабочих и про
пару/семью/социальную жизнь/хейтеров, с доменом · уровнем качества · сферой). Навык никогда не отвечает
из общих знаний: он называет принцип и случай, которые стоят за каждым ходом.

Из 157 обработанных занятий 144 дали библиотеке хотя бы один случай; остальные 13 не оставили при
отборе ни одного случая, пригодного для каталога. Поэтому в текстах говорится о «157 занятиях»
(обработано), а в `casos.json` — 144 идентификатора занятий.

## Как используется этот канон

Это база знаний, которая питает **навык переговоров** (и будущие навыки).
Каждая каноническая запись следует формату: **тезис → закон/механизм → когда применяется → как
исполнять → примеры (сведённые со всего корпуса) → см. также → источник**.

Сквозные понятия (твёрдое и пустое, присоединиться к картине мира, приблизиться к оленю,
управленческий приём (захват — бросок — фиксация), мягко-по-форме/твёрдо-по-сути, право на незнание,
дорога к жизни, сила безразличия) — это **корневые принципы**, см. архитектуру.
