# Спецификация навыка переговоров (Фаза 6) — контракт ответа

Навык построен на каноне (`canon/`) + библиотеке случаев (`casos.json`).
Золотое правило: отвечать ВСЕГДА из канона и случаев, никогда — из общих знаний,
полученных при обучении. Принцип и случай, которые стоят за каждым ходом, ОБЪЯСНЯЮТСЯ простыми словами, а не цитируются как библиография (см. SKILL.md, «Блок канона должен УЧИТЬ, а не цитировать»).

## Реальный ввод (всегда исходить из этого)
Человек описывает свою ситуацию **от первого лица, неполно, субъективно**: выставляет себя
хорошим, забывает факты, (нечаянно) опускает свою часть проблемы и свой настоящий страх.
Навык НЕ принимает рассказ буквально: он его **реконструирует**.

## Вывод — сообщение 1 (полный и немедленный ответ, в этом порядке)
1. **Читаю твою реальную ситуацию** — вернуть человеку его передрягу без прикрас: борьбу, роли,
   чья картина мира правит, твёрдое/пустое, реальный интерес другого,
   страх, который движет человеком, и — ТАКТИЧНО — **его собственную пустоту/слепоту** (мягко по
   форме, твёрдо по сути; никогда не соглашаться с ним из желания угодить). Решение пользователя:
   СКАЗАТЬ ПРЯМО, С ТАКТОМ.
2. **Что это на самом деле** — схема + закон/принцип канона, который ею управляет.
3. **Ход, с точными словами** — конкретное движение и фразы, которые надо сказать,
   с опорой на самый похожий реальный случай из библиотеки (сослаться на него).
4. **Исходя из недосказанного** — 2–3 решающие развилки, каждая разрешена
   («если другой — A → X; если B → Y»). Это делает ответ полным, несмотря на пробелы.

## Слой донастройки (после ответа, а не вместо него)
5. **Для донастройки** — ДО 3 вопросов, и только те, что *перевернули бы* рекомендацию
   (не для заполнения). Идут в конце, помечены как необязательные. У человека уже есть идеальный
   и пригодный ответ без ответов на них. Решение пользователя: ДО 3 ВОПРОСОВ, ЕСЛИ НУЖНЫ.

## Отличие от обычного Claude
- Обычный Claude перед расплывчатым рассказом: допрашивает (нарушает обещание) или угождает (соглашается
  с рассказчиком и усиливает его слепоту).
- Этот навык: распознаёт схему по 275 принципам + 949 случаям, тактично сталкивает с самообманом
  и даёт ход с точными словами и случаем, который его доказывает, — в первом сообщении.
