# Задание: перевод доменного файла канона (ES → RU)

## Что это
Канон — 275 принципов управленческой борьбы и социальной технологии (традиция Владимира
Тарасова, записи занятий Арти Галиева), на испанском. Лицензия CC BY-NC-SA 4.0 — это
адаптация, авторство остаётся за Арти Галиевым; мы делаем точный перевод, не пересказ.

## Обязательное чтение
1. `translation-negociar-ru/glossary.md` — словарь терминов. Применять строго и единообразно. Термин, которого
   в словаре нет, — выбрать по смыслу, записать выбор в отчёт (раздел «пробелы словаря»).
2. `translation-negociar-ru/canon-units/<файл>.src.json` — единицы перевода: `preamble_es` (текст до первого
   `###`) и `units[]` (`index`, `title_es`, `title_en`, `body_es`).

## Правила перевода
- Точность выше гладкости. Не добавлять идей, не смягчать и не усиливать спорные утверждения,
  не «исправлять» автора. Сомнение — отдельной заметкой (см. ниже), не правкой текста.
- Русский простой и разговорный, «для полного новичка», без канцелярита и жаргона; термины —
  только из словаря. Длинные испанские фразы можно делить на предложения, смысл — тот же.
- Прямая речь (в кавычках, курсивом) переводится как речь: с оговорками, разговорными формами,
  без «облагораживания». Различие «утверждение автора / реплика участника / пример /
  рекомендация» сохранять.
- Структура Markdown — один в один: те же маркеры списков, жирный/курсив, кавычки, порядок
  пунктов. Метки пунктов переводить по словарю: `- **Ley / mecanismo:**` → `- **Закон / механизм:**`,
  `- **Cómo se ejecuta:**` → `- **Как исполнять:**`, `- **Cuándo aplica:**` → `- **Когда применяется:**`,
  `- **Ejemplos:**` → `- **Примеры:**`, `- **Ver también:**` → `- **См. также:**`,
  `- *Procedencia:*` → `- *Источник:*` (номера и `#N` после метки — без изменений).
- **Ссылки `[[…]]` оставлять как в источнике — на испанском, дословно.** Их переведёт сборщик по
  единой карте заголовков. Не переводить и не менять текст внутри `[[ ]]`.
- Коды доменов `D1…D11`, имена файлов, числа, проценты, латинские имена людей, названия моделей
  (PPVVC, Solution Selling) — без изменений. «Arti/Artur Galiev» → «Арти Галиев»; «Tarásov» →
  «Тарасов».
- Заголовок принципа (`title_ru`) — короткий, по словарю; английскую часть заголовка не
  переводить (её сохранит сборщик).

## Формат выхода (писать по частям, чтобы не терять работу)
Каталог `translation-negociar-ru/canon-units/<файл>.ru.parts/`:
- `preamble.json` — `{"preamble_ru": "<перевод преамбулы, Markdown>"}`;
- `unit-001.json`, `unit-002.json`, … — по одному файлу на принцип:
  `{"index": 1, "title_ru": "…", "body_ru": "<перевод тела, Markdown, начиная с первой строки после заголовка>", "status": "machine_draft", "notes": ""}`.
  Можно объединять несколько единиц в один файл списком `[ {...}, {...} ]` (например, по 5).
После последней единицы выполнить: `python3 translation-negociar-ru/tools/canon_tools.py merge-parts <файл>` — он должен
сообщить «собрано N/N» и «преамбула: есть». Если чего-то не хватает — дописать и повторить.

## Заметки проверки
Фактическую или логическую неточность источника, непереводимую игру слов, место, где смысл
двусмыслен, — записать строкой в `translation-negociar-ru/translation-review.jsonl`:
`{"file": "<файл>", "index": <номер>, "quote_es": "<цитата>", "issue": "<в чём сомнение>", "proposed": "<предложение>", "status": "open"}`.

## Отчёт в конце

(термин ES → выбранный RU, 1 строка на термин); что не удалось.
