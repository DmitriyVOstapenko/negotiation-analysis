# Пробелы словаря из отчётов переводчиков

Сырьё для выравнивающего прохода (шаг 1). Не словарь — варианты, которые переводчики выбрали
сами; решение принимается при выравнивании.

## batch-002
- gerente: «руководитель отдела продаж» (gerente de ventas), «коммерческий менеджер» (gerente comercial), «финансовый менеджер» (gerente financiero), «менеджер» — нужен единый вариант; jefe de ventas → «начальник продаж»
- posición ventajosa / desventajosa / fuerte → выгодная / невыгодная / сильная позиция
- zona gris → серая зона; golpear el hueco → ударить в пустоту; fuerza mayor → форс-мажор; el fuerte → сильный
- navegar la conversación → вести разговор; lucha (раунд) → борьба; sparring → спарринг
- motivación positiva/negativa → позитивная/негативная мотивация; contrato implícito → неявный контракт
- interceptar el liderazgo → перехватить лидерство; hacer trampa → смухлевать
- director general → генеральный директор; jefe de área → руководитель направления; jefe de planta → начальник производства; director de planta → директор завода; coordinador de calidad → координатор по качеству; responsable técnico → технический руководитель; recepcionista → секретарь на ресепшен; abogada → юристка; «Doctora» (ник) → «Доктор»

## batch-004
- comercial → продажник; gerente de planta → начальник производства; director de planta → директор завода; capacitadora → тренер; terapeuta ocupacional → эрготерапевт
- permanencia → обязательный срок контракта; atención al consumidor → защита прав потребителей; coordinadora de bienestar laboral → координатор по благополучию персонала
- bajar la guardia → опустить защиту; dejarse agarrar → дать себя захватить; luchar por la razón → бороться за правоту
- Inversión/Cambio de roles → Смена ролей; Segunda ronda → Второй раунд

## batch-005
- garra → напор; interceptar la iniciativa → перехватить инициативу; puntos de dolor → болевые точки
- gerente de planta → управляющий заводом (расходится с batch-004!); gerente de ventas → руководитель отдела продаж; líder de soporte → руководитель техподдержки
- ausentismo → невыходы на работу; rotación → текучесть; palabrear → заговаривать
- jefe в свободной речи → «руководитель» (не «начальник»)
- инверсия «duro en forma, suave en contenido» → «твёрдо по форме, мягко по сути»

## batch-006
- supervisor de obra → прораб (сомнение); jefe/gerente comercial → коммерческий директор; jefe de compras → руководитель закупок; encargado de bodega → заведующий складом
- gerente de planta → директор завода (третий вариант!); gerente de sucursal → управляющий отделением; supervisor regional → региональный руководитель
- Alumno → Ученик; Vendedor/Cliente → Продавец/Клиент; framing → рамка, в речи Артура «фрейм»; bajas por estrés → больничные

## Служебные файлы канона
- Eval/Calificación/Veredicto → Оценка/Результат/Вердикт; turno 1 → сообщение 1; Reconciliación → Согласование; tensión → нестыковка
- socio → компаньон; acoso laboral → травля на работе; directos → прямые эфиры; clases → занятия

## Уже видимые расхождения для выравнивания
- gerente de planta: начальник производства / управляющий заводом / директор завода
- gerente comercial: коммерческий менеджер / коммерческий директор
- jefe: руководитель / начальник / шеф
- framing: рамка / фрейм
