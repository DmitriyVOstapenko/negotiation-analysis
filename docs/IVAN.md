# Рядом с Иваном

Плагин переговоров работает без Ивана. Если Иван установлен, его общие инструкции
могут противоречить подтверждению владельца и формату документов переговоров.
На время работы можно отключить конфликтующий плагин в настройках текущей среды.

Публичная поставка не изменяет Ивана. По решению Дмитрия от 2026-11-07 утилита
изменения чужой установки удалена. Личная совместимость будет решаться отдельно;
это решение не означает, что настройки уже изменены или проверены.
История прежнего решения сохранена в [DECISIONS.md](DECISIONS.md).

## Собственная защита переговорной базы

Независимо от соседних плагинов действуют правила переговорной системы:

- согласие на обработку, карта спикеров и сомнительные пункты требуют ответа владельца;
- база меняется после проекта изменений, показанного diff и явного подтверждения;
- исходники встреч и ручные пометки защищены;
- содержание встреч не переносится в чужие журналы сессий.

Защитные проверки плагина дополняют эти правила. Их наличие на диске не доказывает
активацию в хосте. Проверка установки и ограничения — [INSTALL.md](INSTALL.md).

## Что заимствовано из Ивана

Код и идеи взяты по лицензии MIT, © 2026 Maxim Opilkin.
Полный текст — `licenses/third-party/ivan-MIT.txt`:

- `tools/secret_scan.py` — сканер секретов, добавлен шаблон ключа бота Telegram;
- `hooks/_na_hooklib.py`: грамматика заголовков `apply_patch` — по `_host_adapter.py`;
  чтение транскриптов Claude Code и Codex — по `_transcript_io.py`; резервные
  выражения целей записи — по `WRITE_RE` из `post_bash_write_relay.py`, с расширениями.
  Уведомление MIT сохранено в заголовке файла;
- идеи ступенчатой самопроверки, паспорта сборки и пробы интерпретатора в `na.py doctor`;
- явные правила и старшинство инструкций в заданиях субагентам.

Удаление личной утилиты не отменяет атрибуцию кода, который остаётся в проекте.
