| Пересказ чужой просьбы и описание заменённой договорённости — не ложное «договорились» для `na.py eval`; дубль риска — только по главной реплике | три ложных FAIL из восьми в прогоне; ловушки реестра сохранены |
| ИИ-ассистент на встрече — не участник 01; его реплики — материал, не решение людей | сценарий 03; у ассистента нет полномочий и ответственности |
| Год в дате — по дате встречи, без вопроса владельцу; из «до пятницы» дата не вычисляется | исполнители выносили вопрос о годе в каждом разборе |
| ЛПР, названный только должностью и отсутствующий на встрече, — `final_decision_maker: null`, должность в `unresolved`; id не выдумывается | разные исполнители делали по-разному; оба варианта прошли ядро, нужен один |
| Сообщение другой стороне в follow-up — только принятые решения, действующие обязательства, открытые вопросы, следующий шаг; очередь проверки и риски — только в протоколе | в сообщение уходили манипуляции, риски и id — нарушение правила «ничего внутреннего другой стороне» |
| Частичная карта спикеров (часть меток подтверждена) — отдельной задачей v0.6.x | требует статусов по меткам в `review.yaml`, валидаторе и очереди |
| Фикстура `synthetic-meeting`: шесть обязательств обеих сторон, ядро 13 пунктов `core`; «готовы заранее подготовить список вопросов» — не обязательство, 24 лицензии — условие внутри сметы | независимый проверяющий нашёл пропущенные обязательства нашей стороны |

## Ранее подтверждено владельцем (пакет передачи, август 2026)

- Разрабатывается вся система, а не оболочка Negociar.
- Целевые среды: ChatGPT/Codex и Claude Code; результат — на GitHub.
- Архитектура должна поддерживать PLAUD, WonderScribe, локальные файлы, загруженные транскрипты и документы; PLAUD — через аккаунт пользователя; WonderScribe — через переменную окружения `WONDERSCRIBE_API_KEY`.
- Лицензионный гибрид: собственное ядро плюс отдельно лицензируемая русская адаптация Negociar (CC BY-NC-SA 4.0), связь с upstream разрывается, provenance сохраняется.
- Предполагаемый режим использования — некоммерческий.
- Система сама предлагает раскрыть подробный анализ.
- Психологический анализ — рабочая гипотеза с альтернативами; диагноз не выводится.
